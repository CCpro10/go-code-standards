# SVG 自由设计速查（面向飞书画板）

把 SVG 当成 AI 的通用矢量画布。下面是从 14 类典型作品里提炼出的、对画板友好的设计要点。

## 通用原则

- **viewBox 推荐 `1200 × 800` 起步**，复杂作品 `1600 × 1000`，海报类竖版 `900 × 1280`。
- **颜色直接写到属性上**：`fill="#4F46E5"`、`stroke="#1F2937"`，不用 CSS class，不用 `<style>`。
- **避免 `<defs>`、`<filter>`、`<mask>`、`linearGradient`**——画板解析后多半被丢。
  替代方案：渐变用多层半透明矩形；阴影用偏移的次级矩形（`opacity="0.15"`）。
- **文字独立成节点**：每段 `<text>` 写明 `x`、`y`、`font-size`、`fill`，不要嵌套到旋转过的 `<g>`。
- **少用 `<g transform>`**，必要时只用 `translate(...)`，避免 `rotate/scale/matrix` 嵌套。
- **节点数量分级**：≤200 流畅；200–500 可用；>500 拆画板。
- **`<polygon>` 会被降级为不可编辑图片**（实测：同一菱形，`polygon` → `svg` 节点，`<path d="M…Z">` → 可编辑
  `composite_shape`）。需要可编辑的多边形（菱形判断框、梯形、箭头块）一律用 `<path ... Z>`；`<polygon>` 只留给
  ≤15px 的小箭头三角，那种降级无害。
- **文字一律水平**：画板对 `transform="rotate(...)"` 的文字支持差，实测出现乱码。
- **`✓`（U+2713）/ `✕`（U+2715）渲染成豆腐块**，用「是/否」文字或颜色代替；`①②③`、`≠`、`→` 正常。

## 色彩原则（先看这一段再选色）

借鉴 [meodai/skill.color-expert](https://github.com/meodai/skill.color-expert) 的几条强结论，落到我们的飞书画板场景：

1. **在 OKLCH 里思考，烘焙成 sRGB hex 写到 SVG 里**。飞书画板只认硬编码的 `fill="#xxxxxx"` / `rgb(...)`，不能用 `oklch()`、不能用 CSS class。但**选色时**要考虑感知亮度，不要光看 HSL——`hsl(60,100%,50%)` 黄和 `hsl(240,100%,50%)` 蓝同样 L=50%，画到一起黄会"飞出来"压碎蓝。
2. **Hue-first 配色（互补/三角）是弱启发，Character-first 才是强信号**。先决定**性格**（pale / muted / vivid / deep / dark），再在该性格组内挑同感知亮度的色相。下面"按性格分组的色板"已经预先做过亮度对齐。
3. **60-30-10 法则**。一张图里 60% 是主色（通常是背景或最大色块），30% 是次色（卡片/分区），10% 是强调色（数据高亮、按钮、标签）。**不要把 5 个 vivid 色等量铺开**——会出现"三只一样大的猩猩在打架"。
4. **可读性 = 亮度差异，不是色相差异**。背景与文字必须有明显的 L 差距；同色相不同 L 远比不同色相同 L 易读。表格里的 APCA 配对是预先验证过的，可以直接抄。
5. **不要用 `opacity` 偷懒造主色板**。半透明只用于阴影/光晕；正经色块都用实色 hex。

## 按性格分组的色板（OKLCH 亮度已对齐，直接用）

每组内的色相已经按感知亮度（OKLCH L）对齐过，组内任意挑 2-5 个搭配都不会失衡。

### Pale（柔和、信息密度高、长时间阅读 / 看板）

> 适合：信息图、教学插图、儿童向、温和品牌；L≈0.92，C≈0.05-0.10

```
背景      #F8FAFC   #F1F5F9                       ← slate-50/100
分区色块  #DBEAFE  #DCFCE7  #FEF3C7  #FCE7F3  #EDE9FE   ← blue/green/amber/pink/violet 100
中色填充  #BFDBFE  #BBF7D0  #FDE68A  #FBCFE8  #DDD6FE   ← 同色系 200
深色文字  #0F172A  #334155                       ← slate-900/700
强调点缀  #2563EB  #DB2777                       ← 高 C 的 600，仅做小面积高光
```

### Muted（高级、商务、深色文字主导）

> 适合：白皮书、报告、平面图、SaaS 落地页；L≈0.55-0.70，C≈0.10

```
背景      #F8FAFC                             ← slate-50
卡片      #FFFFFF + 边框 #E2E8F0                ← slate-200
文字      #0F172A 标题  #475569 正文           ← slate-900 / slate-600
分类色    #6366F1  #14B8A6  #F59E0B  #EF4444  #94A3B8   ← indigo/teal/amber/red/slate 500，亮度齐
```

### Vivid（商业图表、品牌可视化、对比强烈）

> 适合：飞轮、漏斗、金字塔、Dashboard、营销海报；同号 600 系列**亮度齐**，不会失衡

```
推荐五色  #4F46E5  #9333EA  #DB2777  #D97706  #059669
          indigo   purple   pink     amber    emerald
          ── 全部 600，OKLCH L≈0.50-0.55，搭在一起视觉等重 ──

如果还要一两个补充色：
辅助蓝青  #0284C7   ← sky-600
辅助玫瑰  #E11D48   ← rose-600

⚠️ 避免：直接抄 #F59E0B amber-500（L≈0.77）+ #4F46E5 indigo-600（L≈0.50）混用，
   黄会盖过蓝，整张图重心被拉到右上。
```

### Deep（专业、严肃、医疗 / 金融 / 科技白皮书）

> 适合：年报、技术架构、政府/金融场景；L≈0.30-0.40

```
背景      #F1F5F9                             ← slate-100
深色块    #1E40AF  #5B21B6  #831843  #7C2D12  #064E3B   ← 800-900 各色
          blue-800 violet-800 pink-900 orange-900 emerald-900
高亮文字  #F8FAFC（在深色块上）  #1E293B（在浅背景上）
```

### Dark Mode（赛博、技术感、终端、Dashboard 暗色版）

> 适合：开发者工具、监控大屏、夜间海报；底层接近黑，前景用高 L 的浅色

```
画板底    #0B0F19  或  #020617                ← 接近黑，slate-950
卡片层    #111827  #1E293B                    ← slate-800/900
文字      #E5E7EB（主）  #94A3B8（辅）         ← gray-200 / slate-400
霓虹强调  #38BDF8  #A78BFA  #F472B6  #34D399    ← sky/violet/pink/emerald 400
                                                高 L 高 C，在暗底上"发光"
```

### Editorial / 大地色（插画、地图、历史感）

> 适合：山林、海报、地图、平面图

```
天地     #1E3A8A → #3B82F6 → #60A5FA → #93C5FD → #DBEAFE  ← blue 渐变远到近
大地     #422006  #78350F  #B45309  #D97706  #FBBF24       ← amber 800→400
```

## 文字与背景的对比度速查（APCA 验证）

直接抄这些预先验证过的配对，不用再算（APCA Lc 绝对值 ≥ 60 视为可读，≥ 75 适合长文）。

| 背景 | 文字 | APCA Lc | 用途 |
|---|---|---|---|
| `#F8FAFC` | `#0F172A` | ~95 | 浅背景上的主标题/正文（最常用） |
| `#FFFFFF` | `#1E293B` | ~93 | 卡片内的正文 |
| `#FFFFFF` | `#475569` | ~75 | 卡片内的次级文字 |
| `#0F172A` | `#F8FAFC` | -95 | 暗黑模式正文 |
| `#1E293B` | `#E5E7EB` | -78 | 暗黑模式卡片内正文 |
| `#4F46E5` | `#FFFFFF` | -75 | 主色按钮上的文字 |
| `#FED7AA` | `#7C2D12` | ~85 | 浅暖卡片上的深暖文字（标签） |
| `#DBEAFE` | `#1E40AF` | ~80 | 浅蓝卡片上的深蓝文字 |
| `#0F172A` | `#38BDF8` | -68 | 暗底霓虹强调（用于标题，不用于正文） |

`#94A3B8` slate-400 在 `#FFFFFF` 上 APCA 仅 ~45，**不要**用作正文；可作为图例/辅助说明。

## 配色反模式（容易踩，画板里特别难看）

- ❌ **直接抄 HSL 等距色相**（如 `hsl(0,80%,50%)` / `hsl(120,80%,50%)` / `hsl(240,80%,50%)`）—— 三色感知亮度差很大，绿会刺眼、蓝会沉。改用 OKLCH 对齐过的 600 系列。
- ❌ **vivid 色 ≥ 5 种等量并列**——AI 容易把 5-7 个数据系列全用饱和色铺满，结果整张图"花"。Vivid 系列控制在 ≤ 3 种主色，其余用 muted 或 pale 退到背景。
- ❌ **用 `opacity="0.3"` 把强色调成弱色当主色板**——白板/PNG 导出后透明度复合不一致，颜色会偏。直接用 100/200 系列的实色 hex。
- ❌ **互补色直接拼大面积**（如 indigo + amber 各占一半）——两强相克，没主次。改用 60-30-10：indigo 主 + amber 仅作 10% 强调。
- ❌ **暗模式直接把浅模式 hex 反色**——感知亮度不会反转。暗模式要用专门的 slate-800/900 + sky-400 这种"暗底亮霓虹"组合。
- ❌ **小字配低对比色**（如 `#94A3B8` 字 on `#F1F5F9` 背景）——APCA Lc < 30，画板缩略图里直接消失。小字用上表的 APCA ≥ 75 配对。

## 14 类作品骨架

### 业务图表

- **飞轮**：圆环 = 多个 `<circle>` 嵌套；分段 = `<path d="M ... A r r 0 0 1 ...">`；外围卡片用极坐标 `(cx + r·cosθ, cy + r·sinθ)` 等距分布。
- **鱼骨图**：主骨水平 `<line>`；上下交替支骨用 `<line>` + `<text>`；按 4M1E 5 类配色。
- **价值金字塔**：层与层之间宽度按斜率递减（每层减 80~120px），颜色冷→暖。
- **转化漏斗**：左侧梯形用 `<path d="M…Z">`（需可编辑），右侧 `<text>` 列绝对值/转化率/流失率。
- **路线图**：水平时间轴 `<line>`；事件卡片上下交替；节点 `<circle>` + 引导线 `<line>`。

### UI / 产品

- **SaaS Dashboard**：圆角卡片 `<rect rx="12" ry="12">`；趋势曲线 `<path d="M0,60 C..." stroke="#3B82F6" fill="none">`；环形图弧段用 `<path A>`。
- **移动 App**：iPhone 边框 `<rect rx="48">`；圆形进度环用两个 `<circle>` 叠加（背景灰 + 主色 stroke + `stroke-dasharray`）。
- **海报**：斜切色块 `<polygon>`；大字标题 `<text font-size="120" font-weight="900">`；底部留 QR 区域（200×200 占位 `<rect>`）。

### 信息图 / 工程

- **房屋平面图**：墙体 = 嵌套 `<rect>`（外厚内薄）；门 = `<path d="M x y A r r 0 0 1 ...">` 弧线；区域填色 `opacity="0.3"`；右侧 `<text>` 图例。
- **地铁图**：线路 = `<polyline points="x,y x,y ..." stroke-width="6">`，仅水平/垂直/45° 折角；站点 `<circle r="6">`；换乘 `<ellipse>` 或双圈。
- **化学周期表**：脚本生成 118 个 `<rect>` + 4 行 `<text>`（序数/符号/中文/质量）；按金属/非金属/惰性气体配色。
- **机械时钟**：齿轮 = 圆 + N 个细长 `<rect>` 旋转排列（用 `transform="rotate(angle cx cy)"` 或预先计算坐标）；轴承 = 同心 `<circle>`。

### 艺术 / 插画

> 插画类的山形、剪影本身不需要二次编辑，用 `<polygon>` 降级为图片可以接受；若希望保留可编辑性，改写成 `<path ... Z>`。

- **山林晨景**：远山 `<polygon>` 由远到近三层叠加，颜色由深蓝渐浅；太阳 `<circle>` + 多层 `opacity` 光晕；树用三角形 `<polygon>`。
- **赛博朋克**：底层深色矩形；建筑剪影 `<polygon>` 多层叠（视差）；窗户用百量级小 `<rect>` 网格生成；霓虹 `<line>` 高饱和色。

## 检查清单（投放前）

- [ ] 全部颜色在元素属性上，不依赖 `<style>` / `<defs>`。
- [ ] 没有 `<image href="https://…">` 外链。
- [ ] 文字字号 ≥ 12，关键标题 ≥ 24。
- [ ] 节点总数估算 ≤ 500（窗户/像素阵列谨慎）。
- [ ] `viewBox` 比例与目标画面一致，没有大片空白或被裁切。
- [ ] 本地用 `whiteboard-cli -o preview.png` 看一眼，再决定是否投放。
